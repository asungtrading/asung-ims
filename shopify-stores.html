Each row is one Shopify store IMS talks to. Price and Compare-at are the price tiers sent to Shopify — Compare-at can be the same tier as Price or left empty (sale prices are set by the Wholesale All In One app). Each Shopify location must be paired with one IMS warehouse — stock and shipping use only these pairs. Press a row to see its locations, then Check connection to read the store's live locations from Shopify. A store is Live only after an admin presses Go live — until then IMS only reads it and writes nothing to Shopify. Only an admin can add or change stores and pairs.
